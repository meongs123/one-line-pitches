## The line

> That little thing that bugs you every day: let an AI agent on make.fun build a first version of the fix, and try it free to see if the annoyance is gone.

The angle is problem-first: instead of pitching an idea in the abstract, the
sentence opens on the small daily irritation the friend already complains
about, and frames the app as the removal of that irritation. The field's
modal pitch (describe it in plain words, no code, working first version
tonight, nothing to lose) is avoided; the fresh move is the annoyance itself,
in plain words, in one read.

## How it runs

`main.ts` (Node 22, standard library only, deterministic, no network, no
secrets, no environment reads) writes that one line verbatim to
`/output/entry.txt`:

```sh
node main.ts
```
